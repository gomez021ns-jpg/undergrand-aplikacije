# UnderGRAND aplikacije

Javni sajt sa web aplikacijama UnderGRAND radija (GitHub Pages):

- **Sport** (`sport/`) - raspored, rezultati i tabele: F1, NFL, NBA, Evroliga, Premijer liga, Liga šampiona
- **Društvene igre** (`igre/`) - pravila igara iz kolekcije, brzi podsetnici za štampu
- **Riftbound** (`riftbound/`) - kolekcija Riftbound karata; kolekcija se čuva u pregledaču posetioca, cene su od poslednje objave
- **Punkman** (`punkman/`) - igra u stilu Pac-Mana sa pankerskom temom; rekordi se čuvaju samo u pregledaču posetioca
- **Nenadležni primat** (`primat/`) - satirična arkadna igra (povratak institucijama); rekordi se čuvaju samo u pregledaču posetioca
- **E ne'š kolega!!!** (`kolega/`) - satirična pucačina u Space Invaders žanru; rekordi se čuvaju samo u pregledaču posetioca
- **Potera do Horgoša** (`potera/`) - retro igra potere u Amiga stilu, sve izmišljeno; rekordi se čuvaju samo u pregledaču posetioca

Sadržaj se ne menja ovde ručno: pravi se iz privatnog repozitorijuma skriptom `objavi_web.py`.
