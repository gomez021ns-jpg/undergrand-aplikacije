# UnderGRAND aplikacije

Javni sajt sa web aplikacijama UnderGRAND radija (GitHub Pages):

- **Sport** (`sport/`) - raspored, rezultati i tabele: F1, NFL, NBA, Evroliga, Premijer liga, Liga šampiona
- **Društvene igre** (`igre/`) - pravila igara iz kolekcije, brzi podsetnici za štampu
- **Statistika** (`statistika/`) - posete sajta i Zeno izveštaji; radi sa fajlom baze na računaru korisnika

Sadržaj se ne menja ovde ručno: pravi se iz privatnog repozitorijuma skriptom `objavi_web.py`.
